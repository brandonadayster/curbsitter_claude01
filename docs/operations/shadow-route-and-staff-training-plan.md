# Shadow-Route & Staff Training Plan — DRAFT

> Resolves P7-06. Prepares runner(s) and admin/dispatch to run real routes
> reliably before customers depend on them.

## Who trains on what

| Role | Must be able to |
|---|---|
| Runner | Read a task, follow rollout/return SOPs, reveal access in-app, capture proof, record exceptions, stop for safety, file incidents |
| Admin/Dispatch | Approve serviceability reviews, generate cycles, build/assign routes, triage exceptions, schedule rechecks, handle support, run reports |
| Owner | All of the above + activation decisions, billing, incident lead |

## Training sequence

1. **Orientation:** the promise ("bins out, bins back, photo-confirmed"), the hard
   boundaries (no hauling, no time guarantees, private photos, access-secret
   handling), and safety-first culture.
2. **App walkthrough (runner):** sign in, today's route, task detail, access
   reveal, proof photo, complete, exception, incident report — on a real phone.
3. **App walkthrough (admin):** review queue → approve → generate cycles → build
   route → assign → monitor → exceptions/rechecks → reports.
4. **SOP practice:** rollout SOP and return SOP (from OPERATIONS_PLAYBOOK), gate/
   access-failure handling, hauler-delay handling, weather/animal safety.
5. **Assessment:** each runner completes a full simulated stop from the PWA
   **without verbal coaching** (an MVP success criterion).

## Shadow routes (before live paying customers)

- Run `[1–2]` **shadow cycles** on friendly/founder addresses: perform the full
  rollout→collection→return with real proof photos and at least one injected
  exception (e.g., simulate a hauler delay) to exercise the recheck path.
- Debrief: capture actual task times by property complexity (feeds route
  economics), photo upload reliability, and any confusion points.
- Do not expand until service quality is predictable without founder heroics.

## Readiness sign-off

- [ ] Each runner passed the unassisted-stop assessment.
- [ ] Admin/dispatch completed an end-to-end dry run.
- [ ] Shadow cycles completed with proof + one exception resolved.
- [ ] Actual task times recorded and route assumptions updated.
- [ ] Safety/incident procedure rehearsed.
